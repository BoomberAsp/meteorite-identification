# 中期报告

## 1. 数据集理解

### 1.1 数据来源与描述

本任务为陨石图像二分类：判断给定图像中是否包含陨石。训练集包含5098张图像，每张图像对应一个二值标签（1表示含陨石，0表示不含），测试集不含标签。图像格式包括 `.jpg`、`.jpeg` 和 `.png`，原始尺寸差异极大（如400×300 、4032×3024 ）。

### 1.2 探索性数据分析

通过初步统计，主要发现如下：

- **尺寸不一致**：图像宽高比各异，无法直接输入神经网络。
- **目标尺度变化剧烈**：
  - 部分图像中陨石占据主要区域（甚至只显示局部）；
  - 更多图像中陨石占比很小，周围存在大量留白（如桌面、地面背景）。
- **背景复杂**：许多图像包含手、文字标签、尺子、牌子等与陨石语义无关的干扰物。
- **清晰度差异**：部分图像存在运动模糊或低分辨率，影响特征提取。
- **类别统计**： 类别 0: 计数 = 2413, 比例 = 47.33%
类别 1: 计数 = 2685, 比例 = 52.67%

这些问题直接影响了分类器的鲁棒性：如果单纯使用全局缩放，小目标陨石容易被忽略；背景中的干扰可能导致模型学到虚假关联；清晰度差异则要求模型具备一定的抗噪能力。

### 1.3 数据预处理

基于上述分析，我们设计了如下预处理流水线（代码位于 `dataset.py` 和 `train.py`）：

- **统一尺寸**：使用 `transforms.Resize` 对验证/测试图像直接缩放到 `input_size`（默认300）；训练阶段采用 `RandomResizedCrop`，先放大再随机裁剪，既统一尺寸又增加尺度多样性。
- **数据增强（训练集）**：
  - 随机水平翻转（`RandomHorizontalFlip`）增强方向不变性；
  - 随机旋转 ±10°（`RandomRotation`）模拟拍摄角度变化；
  - 颜色抖动（`ColorJitter`：亮度、对比度、饱和度各±0.2）降低光照敏感度；
  - 上述操作均使用 ImageNet 的均值和标准差进行归一化，便于迁移学习。
- **正则化技巧**：支持 MixUp（`mixup_data`）和标签平滑（`label_smoothing_loss`），减少过拟合。
- **无标签测试集**：仅做 resize + 归一化，保持确定性。

## 2. 初步实验结果

### 2.1 模型选择

我们选取了2种代表性架构进行初步实验：

- **ResNet50**：经典残差网络，在ImageNet上预训练，作为基线。
- **EfficientNet-B3**：兼具精度与效率，通过复合缩放平衡深度/宽度/分辨率，被证明对细粒度分类和小目标较友好。

选择依据：所有模型均使用 ImageNet 预训练权重，利用迁移学习缓解陨石数据量不足的问题；EfficientNet 的自动缩放策略理论上对不规则目标尺度更鲁棒。

### 2.2 实验设置

- **超参数**（参考 `train.py` 默认值）：
  - Epochs = 50
  - Batch size = 16
  - 初始学习率 = 1e-5
  - 优化器 = Adam
  - 学习率调度 = CosineAnnealingLR
  - 损失函数 = 交叉熵（对比Focal Loss）
  - 分层学习率：主干网络 lr×0.1，分类头 lr×1
  - MixUp alpha = 0.2（默认启用）
- **评价指标**：验证集上的二分类 F1 分数（因类别不平衡，F1 比准确率更具参考价值）；同时搜索最优分类阈值（0.3~0.8）以最大化 F1。

## 3. 计划提升方向

基于上述初步结果，我们提出以下改进计划，按优先级排序：

### 3.1 数据层面（高优先级）

- **针对性数据增强**：增加 `RandomErasing`（随机擦除）模拟背景遮挡，强迫模型关注陨石本体；增加 `GaussianBlur` 模拟不同清晰度，提升对模糊图像的鲁棒性。
- **自动裁剪留白**：训练前离线检测陨石的最小包围框（如利用简单的边缘检测或YOLO目标检测器），裁剪掉大量无关背景后重新缩放。预期可提高小目标样本的 F1 约 5~8%。
- **类别不平衡处理**：除 Focal Loss 外，使用加权随机采样（`WeightedRandomSampler`）使正负样本在每个 batch 中更均衡。

### 3.2 模型与训练策略（中优先级）

- **引入注意力机制**：在 EfficientNet 的瓶颈层后添加 CBAM（卷积注意力模块）或 SE 模块，让模型更聚焦于陨石区域而非背景文字/手。
- **测试时增强（TTA）**：已在 `predict.py` 中实现水平翻转 TTA，后续可加入多尺度测试（如 300×300 和 380×380 两个尺寸的平均概率）以提升稳定性。
- **模型集成**：对 ResNet50、EfficientNet-B3 和 DenseNet121 的预测概率进行加权平均，进一步降低方差。

### 3.3 后处理与阈值调优（低优先级）

- **自适应阈值**：根据验证集的置信度分布，尝试基于 F1 最大化的多项式插值阈值，而非简单的网格搜索。
- **困难样本挖掘**：对验证集中预测错误的样本进行可视化分析，总结误判模式（如光照过暗、陨石被手遮挡），针对性地增加合成训练数据。

**预期效果**：通过上述改进，我们期望将验证 F1 从当前的 0.99 进一步提升。

## 4. 结论

目前我们已完成以下工作：
- 深入分析了陨石数据集的特点，识别出尺度不一、背景杂乱、小目标留白等关键挑战；
- 实现了完整的训练与推理代码（`dataset.py`、`model.py`、`train.py`、`predict.py`），集成了 MixUp、标签平滑、分层学习率、Focal Loss 等技巧；
- 通过初步实验确认 EfficientNet-B3 配合数据增强能够达到 0.91 的验证 F1，验证了方案的有效性。

项目下一步重点为：
- 实施自动裁剪留白和随机擦除增强，针对性解决小目标问题；
- 引入注意力模块和模型集成，进一步提升泛化能力；
- 进行更细致超参数搜索。

预期在最终报告中，我们能够交付一个在 Kaggle 上达到高 F1 分数、且具有较强鲁棒性的陨石分类模型。
